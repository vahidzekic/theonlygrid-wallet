So funktioniert TOG Wallet

Kurz: Der Schlüssel entsteht auf Ihrem Gerät, die App erstellt und signiert jede Transaktion, und der Server leitet sie nur ans Netz weiter.

Woher der Schlüssel kommt

Wenn Sie ein TOG-Konto anlegen, erzeugt Ihr Gerät einen zufälligen Hauptschlüssel. Daraus leitet die App nach derselben Regel wie die TOG Console Ihren Hub-Signaturschlüssel (Ed25519) ab, und daraus Ihre Adresse. Deshalb ist die Adresse auf jedem Gerät dieselbe.

Der TOG-Kontodienst bewahrt den Hauptschlüssel nur gesperrt auf: durch Ihr Passwort, durch die 24 Wörter und durch die Schlüssel Ihrer Geräte. Er kann ihn nicht entsperren. Auf dem Gerät liegen die Schlüssel im Schlüsselspeicher des Systems (Keychain, Credential Manager, Android Keystore, Secret Service).

Was beim Senden passiert

  1. Die App fragt das Netz nach Ihrem Guthaben und Ihrer nächsten Transaktionsnummer.
  2. Sie erstellt die Transaktion selbst: Netz, Sie, Empfänger, Betrag, Nummer. Sie signiert nie etwas, das der Server schickt.
  3. Nach Ihrer Bestätigung signiert sie mit dem Schlüssel auf Ihrem Gerät und schickt sie an den Server, der sie an den Hub weitergibt.
  4. Sobald die Transaktion in einem Block ist, zeigt die App sie als ausgeführt.

Der Server könnte ein falsches Guthaben anzeigen, aber keine Transaktion erstellen oder ändern, die Sie nicht bestätigt haben. Die Prüfung von Guthaben mit Beweisen aus dem Netz (Light Client) kommt in einer späteren Version.

Was der Server sieht

Das öffentliche RPC-Gateway (rpc.theonlygrid.com) sieht Ihre IP-Adresse, die Adresse, die Sie abfragen, und die Transaktionen, die Sie senden. All das ist im Netz ohnehin öffentlich, außer der Verbindung zwischen IP und Adresse, die das Gateway nur kurz in seinen Protokollen hält. Siehe Datenschutzerklärung.

Netz und Adressen

Eine Adresse hat 20 Bytes, angezeigt als 0x und 40 Hex-Zeichen, gleich auf dem Hub und allen TOG-Chains. Jede Transaktion trägt eine Netzkennung, daher gilt eine Testnetz-Transaktion nicht im Hauptnetz. Die App prüft die Kennung vor jeder Überweisung und zeigt deutlich TESTNET.

Die technische Beschreibung ist die Spezifikation TOG-SPEC-0023.

TOG Wallet ist eine Testversion im Testnetz von The Only Grid. Test-TOG hat keinen Geldwert.
